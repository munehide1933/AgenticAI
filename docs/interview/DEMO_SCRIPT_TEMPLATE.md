# Demo Script (3-5 min)

## 0. Setup (20s)
- Project name and goal in one sentence.
- What is public vs private in your architecture.

## 1. User Flow (90s)
- Start a new session.
- Ask a non-trivial question.
- Show streaming output and reasoning path.
- Show optional deep thinking/web search toggle.

## 2. Engineering Depth (90s)
- Open one core file and explain one key trade-off.
- Explain one failure path and how it is handled.
- Show one extensibility point (private hooks).

## 3. Results (40s)
- Latency and token/cost numbers.
- Success/failure rate from your recent runs.

## 4. Close (20s)
- What you would ship next for production readiness.
